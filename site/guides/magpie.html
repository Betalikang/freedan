先搞懂：它到底在干嘛

打个比方。Magpie 就像装在你电脑上的一个总机：左边接进你已有的各家订阅和账号，右边对外只露一个大家都认识的地址 http://127.0.0.1:3425/v1。各路工具只管拨这个总机，报一个模型名字，总机负责把请求转给对应的订阅，流式输出、工具调用这些都在中间翻译好。

左边的「线路」有三种接法，这篇都会讲到：

  • 订阅插件（重点）：在它的插件市场里装一个对应工具的插件，登录你自己的账号，这家订阅里的模型就进总机了。Qoder、WorkBuddy、ZCode、Antigravity 都有现成插件。
  • 官方 API key：有 DeepSeek、GLM、Kimi 这类官方 key 的，选对应厂商贴上 key 就行。
  • 自定义接口：你手里已经有一个本地接口（比如照上一篇 WorkBuddy 攻略搭好的 WorkBuddy2API），把地址填进来就能用，几条线路可以并存。

Magpie 本身是 MIT 开源的，官网 usemagpie.ai，Windows、macOS、Linux 都是单个文件跑起来。它只监听你自己这台电脑，不往公网暴露。

准备这几样

  • 一台电脑，本文以 Windows 为例，Mac 和 Linux 流程一样。
  • 你已经有的账号或订阅（Qoder、WorkBuddy 等），能在官方客户端正常登录就行。还没有 Qoder 国内账号的朋友，可以先走我的邀请链接注册：Qoder 注册入口。用我的链接注册，我也能跟着吃一口资源点赠送😋，先谢过！（本文例子用的就是国内版 qoder.cn）
  • 网络环境：下载和装插件要走国外源，直连不顺的话先把代理备好在旁边；插件页里也有国内镜像开关，后面会讲。

第 1 步：下载安装

  • 打开官网 usemagpie.ai 下载 Windows 版；也可以去它的发布页 GitHub Releases 拿最新的 Windows 包。
  • 解压到一个固定的英文目录，比如 E:\Tools\magpie，以后别挪来挪去。目录里看到 magpie.exe 就是齐了。
  • 第一次双击可能被 SmartScreen 拦一下（Windows 版还没签名），点「更多信息 → 仍要运行」即可。

做到啥样算成：窗口能打开，右下角托盘里多出一个 magpie 图标。

第 2 步：打开窗口，认识一下界面

点托盘里的 magpie 图标就能打开窗口（窗口关了图标还在，总机就还活着，不用重新开）。窗口里几个页签先认个脸熟，后面每一步都会用到：

  • Agents（工具列表）：你电脑上装的 AI 工具都列在这里，每个工具当前用哪个模型一目了然，点一下就能换。
  • Providers（线路）：接进来的各家订阅和 key 都在这管，登录、选模型、测试都从这里进。
  • Usage（用量）：谁用了多少、各家订阅还剩多少、每日签到，都在这看。
  • Settings（设置）里的 Plugins（插件）页：插件市场，装插件、卸插件、开国内镜像都在这。

总机这时候已经在跑了，地址就是 http://127.0.0.1:3425/v1，先记着，第 6 步往工具里填的就是它。

第 3 步：逛插件市场，装上你要的工具

这一步把「Qoder 的订阅」变成「总机里的一条线路」，全程点鼠标：

  • 打开 Settings（设置）→ Plugins（插件），切到 Discover（发现） 页签，这就是插件市场。
  • 在市场里搜工具名字：想用 Qoder 就搜 qoder，想用 WorkBuddy 就搜 workbuddy，ZCode 搜 zcode，Antigravity（反重力）搜 antigravity。
  • 找到对应的插件卡片，点安装。一个插件常常把一家工具的几条线路都带上了，比如 Qoder 的插件同时带国际版、国内版和千问办公，WorkBuddy 的插件同时带国内版和海外版，装一次就够。
  • 装完切回 Installed（已安装） 页签，能看到刚装的插件列在里面，就是装好了。

下载慢或者转圈失败？ 插件页上有个 Mirrors in China（国内镜像） 开关，打开它，下载会先走国内镜像源，装完再关掉也行。开着系统代理的话它也会跟着走。

做到啥样算成：Installed 列表里能看到你要的那个插件。

第 4 步：登录你的账号

插件装好了，接着告诉它「用我的哪个账号」：

  • 点窗口里的 Add provider（添加线路）→ From plugins（来自插件），这里列着已装插件能登录的所有线路。
  • 挑你要的那条点进去。注意分清版本：Qoder 国内账号选 Qoder CN（qoder.cn），国际账号选 Qoder；WorkBuddy 国内选 WorkBuddy，海外选 WorkBuddy AI，两家的账号不互通，选错了登不上。
  • 它会列出几种登录方式让你选，常见的有三种： 浏览器授权（推荐）：点一下自动打开对应官方的登录页，用你平时的账号登录、点授权，回来就登好了，跟扫码登录一个感觉，什么都不用抄。
  • PAT（个人访问令牌）：不想走浏览器授权时选这个。先去对应官网的账号集成页生成一个令牌（Qoder 在 qoder.cn/account/integrations，国际版在 qoder.com 同路径），贴进来即可，有效期最长一年。
  • API key：部分工具支持直接贴官方 key（比如 WorkBuddy 在官网 profile/keys 页生成的 key），有就贴，没有就走浏览器。
  • 登录成功后回到 Providers（线路） 页，这条线路会显示你的账号名和它带来的模型列表。

做到啥样算成：Providers 里这条线路显示已登录，模型列表不是空的。每个账号实际有哪些模型以它自己的列表为准，别抄别人的。

第 5 步：登录后可能让你做的几个配置

登完账号不一定马上完事，窗口里可能还会让你做这几样选择，都不难，按需点就行：

  • 选用哪些模型：点开这条线路的设置，能看到它带来的全部模型，默认全露出来。用不了那么多的，可以把不想要的勾掉，工具那边就只看到你留下的；以后新出的模型想不想自动进来，也有开关。
  • 插件自带的小开关（Plugin options）：有些插件会在线路设置里多给几个开关，用插件自己的话写着说明。比如 WorkBuddy 有个「只用免费模型」开关，打开后只列当下不花额度的模型，其余请求直接拦下，不用担心误花额度；默认是关的，按自己需要点。
  • 每日签到：不少工具官方有每日签到送额度或保活的机制，magpie 可以替你每天自动点。开关在 Settings（设置）→ Usage（用量）→ Plugins（插件签到） 里，每个插件一个开关，打开就每天自动签；Usage 页的账号卡片上还有个「Check in now（立即签到）」按钮，想马上补签一次点它就行。多个账号的还能逐个开关。比如 Qoder 每天签一次有每日额度拿，WorkBuddy 国内版签到保活，都建议顺手打开。要是哪天签到提示要验证码，它会明说让你去官方客户端里点，它不替你过验证码。

做到啥样算成：模型列表是你想要的样子，签到开关按需要打开了。这一步没做完也不影响后面使用，随时回来补。

第 6 步：把模型接进你干活的工具

线路有了，最后一步是让 ZCode 这类工具用上它。两条路任选：

路 A：让 magpie 替你改（最省事）。 打开 Agents（工具列表） 页，找到 ZCode 那一行，点它的模型栏，在弹出的列表里挑一个刚接进来的模型（名字形如 qoder-cn/xxx，前面是线路名、后面是模型名）。点完 magpie 自己去改 ZCode 的配置文件，只动模型那一个键，别的原样不碰。列表里没有的工具走路 B 的三件套手填。

做到啥样算成：重开工具后，模型列表里能看到刚接进来的模型。

第 7 步：真刀真枪试一次（必须做）

别只发一句「你好」就宣布成功。标准动作是：新开一个 agent 对话，选刚接的模型，让它「新建一个测试文件，写一句话进去，读出来，最后删掉」。全程看它能不能正常调工具，能连着做完才算过，只陪聊不干活不算数。

做到啥样算成：建文件、读文件、删文件三个动作都顺利完成。到这里整条链路就通了，以后换工具、换模型都是重复第 6 步。

已有本地接口的，直接插进来

如果你照WorkBuddy 接入攻略已经搭好了本地的 WorkBuddy2API，不必再走插件登录：点 Add provider（添加线路）→ Custom（自定义），给它起个名字，地址填 http://127.0.0.1:7863/v1，key 填你当时设的那串，模型照面板里的 id 逐个填上，保存就多了一条线路。官方 key 类的更简单，Add provider 里选对应厂商的卡片贴 key 即可。自定义线路和插件线路互不冲突，各走各的。

跑起来之后，平时怎么用

  • 开机顺序：先让 magpie 跑起来（托盘有图标），再开干活的工具。想开机自动有，把 magpie.exe 的快捷方式放进启动文件夹（资源管理器地址栏输 shell:startup）最省事。
  • 换模型：Agents 页点哪个工具就换哪个，不用再去翻各工具自己的设置。一套顺手的搭配可以存成档案（Profiles），一键整套切回。
  • 看用量和签到：Usage 页看每条线路跑了多少请求、各订阅还剩多少，签到结果也写在账号卡片上。
  • 自动兜底：几条线路可以编成一个路由组（Routing），一条失败了自动试下一条，组名形如 auto/xxx，工具里选这个组名就行。
  • 插件更新：隔段时间去 Plugins 页看看有没有更新，上游接口变了社区插件会跟着修。

必须知道的风险（花一分钟看完）

  • Magpie 本体是开源的，但订阅插件是社区维护的非官方通道，上游随时可能加严风控，今天能用不代表永远能用，平常心。
  • 只用自己的账号，小规模自己玩。批量搞小号、拿去卖钱，既违规，也会连累大家都没得用。
  • 登录凭证存在你自己电脑上（用户目录下的 .config/magpie 文件夹），电脑别借人，这个目录别同步网盘，key 和凭证别截图发群。
  • 总机默认只听你自己这台电脑，别往公网暴露；确有跨机需求按官方文档走加密配置，别裸奔。
  • 各家订阅的服务条款不一样，这种用法是否符合你账号的条款，自己评估清楚再动手，这篇只记录技术路径。
